# Megarieltor — Лендинг агентства элитной недвижимости

Одностраничный сайт-визитка агентства недвижимости **Megarieltor** в Ташкенте. Проект представляет собой адаптивный лендинг с каталогом объектов, фильтрами, избранным и формой заявки, интегрированной с Google Forms.

## Возможности

- 🏠 **Каталог объектов** — квартиры, дома и коммерческая недвижимость с фильтрацией по типу, району и цене
- 🔍 **Поиск** по названию, району и описанию объекта
- ⭐ **Избранное** — сохранение понравившихся объектов в `localStorage`
- 🪟 **Модальное окно** с подробной информацией об объекте
- 📩 **Форма заявки** с отправкой в Google Forms и локальным резервным сохранением
- 📱 **Адаптивная вёрстка** — корректно работает на мобильных, планшетах и десктопе
- 🎨 **Плавные анимации** — hover-эффекты, slow zoom фонового изображения, pulse-анимация кнопки звонка
- 💬 **Toast-уведомления** о результате отправки формы
- 📞 **Плавающая кнопка звонка** и кликабельные контакты (tel, mailto, Telegram)

## Стек и инструменты

- **HTML5** — семантическая разметка
- **CSS3** — кастомные свойства (CSS-переменные), Grid, Flexbox, анимации, backdrop-filter
- **JavaScript (Vanilla, ES6+)** — без фреймворков и библиотек
- **Google Fonts** — Playfair Display, Inter
- **Google Forms** — приём заявок с сайта
- **Unsplash** — изображения объектов
- **Git / GitHub** — контроль версий

## Как запустить

Проект не требует сборки и зависимостей — это чистый статический сайт.

### 1. Клонировать репозиторий

```bash
git clone https://github.com/mgrieltor/megarieltor.git
cd megarieltor
```

### 2. Открыть в браузере

Просто открой файл `index.html` двойным кликом, либо запусти локальный сервер:

```bash
# вариант с Python
python -m http.server 8000

# вариант с Node.js (npx)
npx serve .
```

Затем открой в браузере `http://localhost:8000`.

## Настройка формы заявок (Google Forms)

По умолчанию форма использует плейсхолдер. Чтобы заявки приходили в твою Google-таблицу:

1. Создай Google-форму с полями **Имя**, **Телефон**, **Сообщение**
2. Открой форму → **Отправить** → скопируй ссылку и замени `/viewform` на `/formResponse`
3. Открой форму в режиме просмотра, посмотри исходный код страницы и найди `entry.XXXXXXX` для каждого поля
4. Подставь свои значения в начало файла `script.js`:

```js
const GOOGLE_FORM_ACTION = 'https://docs.google.com/forms/d/e/ТВОЙ_ID/formResponse';
const FORM_ENTRY_NAME    = 'entry.1000001';
const FORM_ENTRY_PHONE   = 'entry.1000002';
const FORM_ENTRY_MESSAGE = 'entry.1000003';
```

Все заявки также дублируются в `localStorage` (ключ `megarieltor_leads`) на случай сбоя сети.

## Кастомизация контента

- **Объекты недвижимости** — массив `properties` в начале `script.js`
- **Цвета и шрифты** — CSS-переменные в `:root` в файле `style.css`
- **Команда и новости** — статичные блоки в `index.html`
